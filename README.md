FeedingHands Initiative 🌱
FeedingHands Initiative is a responsive NGO website developed to create awareness about social and environmental activities and encourage people to participate through volunteering and donations. The website provides information about the organization's mission, vision, impact, team, and different ways to get involved.
✨ Features
- 🏠 Home Page with mission, vision, and impact information
- ℹ️ About Us with organization details, values, and team members
- 🤝 Volunteer Registration with an online interest form
- 💰 Donation Section with different contribution options
- 📞 Contact Page with contact details and contact form
- 🗺️ Google Maps Integration for location
- 📱 Responsive Design for desktop, tablet, and mobile
- 🎨 Interactive UI with animations, icons, and image carousel
- 📋 Form validation and submission confirmation
🛠️ Technologies Used
- HTML5 for website structure
- CSS3 for styling, animations, and responsive layouts
- JavaScript for interactive functionality
- Font Awesome for icons
- Google Maps for location integration

🚀 How to Run
1. Download or clone the repository.
2. Open the project in Visual Studio Code.
3. Open index.html.
4. Run it using Live Server or directly in a web browser.
No backend or database setup is required.
